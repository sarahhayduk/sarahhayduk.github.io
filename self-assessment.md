# Professional Self-Assessment
Throughout my Computer Science program and the development of the ePortfolio, I have gained a clear understanding of my strengths as a software engineer and how I want to position myself professionally. Revisiting and enhancing key artifacts from earlier courses helped me refine the engineering practices I value most: writing reliable, well-structured code, designing solutions with clarity and intent, and approaching problems with a security-first mindset. This portfolio represents the discipline I have built and the direction I am committed to pursuing as I enter the field.

A major theme throughout my program has been learning how to collaborate effectively and communicate technical ideas clearly. Working through design documents, test plans, and iterative feedback taught me how to explain decisions to both technical and non-technical audiences. These communication skills became essential during my enhancements, where I had to justify architectural changes, document system behavior, and articulate the reasoning behind each redesign. Whether restructuring arithmetic logic, refining a search algorithm, or externalizing sensitive data into a database, I learned to better communicate what I built and why I built it that way.

As the program progressed, software engineering and defensive coding became central to my development. Transforming the Numeric Overflow Coding Activity into a modular SafeArithmetic component required me to think like a systems engineer: understanding numeric boundaries, preventing undefined behavior, and designing reusable logic that behaves predictably across all C++ numeric types. This enhancement taught me how to design maintainable components that anticipate failure modes and reflect real-world engineering expectations.

My coursework strengthened my foundation in programming, algorithms, and system-level reasoning. I learned how to evaluate computational tradeoffs, analyze data flow, and design solutions that balance correctness, performance, and maintainability. These skills were especially important when enhancing the Grazioso Salvare Rescue Dog Dashboard, where I redesigned the breed-matching logic into a dual-mode algorithm and managed the interaction between backend queries and UI state. That work reinforced my ability to think algorithmically while also considering user experience and system behavior.

Security emerged as one of the strongest threads running through my work. I learned how vulnerabilities arise, how attackers think, and how to design software that anticipates adversarial behavior. This mindset shaped my most complex enhancement, where I converted a reverse-engineered, hardcoded, single-file C++ Client Service Management program into a secure, database-backed system. I externalized all sensitive data into SQLite, implemented prepared statements, added defensive error silencing, introduced RAII-based resource management, and integrated Argon2id password hashing through a lightweight embedded cryptographic library. These changes ensured that no plaintext credentials exist in the source code, seed script, or resulting database, and that internal errors never leak to the user interface. This enhancement reflects the security-focused engineering approach I intend to carry into my career.

Together, the artifacts in this portfolio form a cohesive picture of my abilities. The SafeArithmetic module demonstrates disciplined, defensive C++ engineering and modular design. The Grazioso Salvare dashboard showcases my ability to design and evaluate algorithms, manage data structures, and coordinate UI behavior. The Client Service Management System highlights secure data handling, separation of concerns, cryptographic hardening, and a mindset informed by reverse engineering. While each artifact focuses on a different area (Software Engineering and Design, Algorithms and Data Structures, and Databases), the skills overlap and they collectively show that I can think in high-level systems, low-level software, reason about tradeoffs, adapt my toolchain, and build solutions that are both practical and robust.

Developing this ePortfolio has helped me grow and showcase my strengths, clarify my professional goals, and prepare to enter the field with confidence. The work represented here demonstrates that I can design maintainable components, analyze and improve algorithms, handle data securely, and communicate my decisions clearly. It is both a record of what I have accomplished in my Computer Science program and a foundation for the kind of engineer I intend to be moving forward.
